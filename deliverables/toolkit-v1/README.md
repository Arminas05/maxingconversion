# The Sales Page + VSL Toolkit — v1

Two Claude Skills:

1. **sales-page-builder** — turns an offer description into a complete,
   working HTML sales page (problem, proof, offer, price, guarantee, FAQ,
   close).
2. **vsl-script-builder** — turns an offer description into a complete,
   film-ready video sales letter script.

Start with `INSTALL.md` to get them running, then just describe your offer
to Claude and ask for a page or a script.

No subscription. No upsell gate on these files. They're yours to run on
every offer you launch, and on client work if you do client work. You may
not resell or redistribute the skill files themselves.
