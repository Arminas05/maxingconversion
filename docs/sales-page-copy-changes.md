# Changes to the hand-written copy on /sales-page/

The copy is Arminas's and is kept verbatim. Everything altered is listed
here so any of it can be reverted in one edit.

## 1. Implied endorsement by a named real person — CHANGED, do not revert as-was

**Original:** "Even Iman Gadzhi or Any Creator You've Seen Uses this to Easily
Generate NEW Leads And Sales For Their Business…"

**Now:** "Even Iman Gadzhi, or any creator you've seen, has a sales page —
that's how they Easily Generate NEW Leads And Sales For Their Business…"

On a page selling this service, "uses **this**" reads as though Iman Gadzhi
is a client or endorser. He has not agreed to that, and it isn't ours to
claim — that's a false-endorsement problem regardless of intent, and it is
the one item here that isn't a matter of taste.

The rewrite keeps his name and keeps the point (successful creators all have
sales pages, which is true and checkable). If the intended meaning really was
"uses a sales page", this now says that unambiguously.

## 2. Arithmetic — FIXED

The itemised values are 2997 + 499 + 194 + 747 + 997 = **$5,434**.
The copy said "Total value of $5,434" but then "$5,431" twice afterwards.
Both instances now read $5,434 so the page doesn't contradict its own maths.

## 3. Income figures — KEPT, with the caveat moved next to them

"$10 000", "Six Figures", "10X or 50X" are all kept as written. A short
illustrative-figures disclaimer now sits directly beneath them, and links to
the Earnings Disclaimer, rather than only appearing in the footer. A page
that names a number should name the caveat in the same breath — footer-only
disclaimers are the pattern regulators treat as inadequate.
